# Local draft branch cleanup after PR creation

Run this after the formal PR has been created or updated and read back with the expected delivery branch and final HEAD. It is part of the authorized implementation workflow; no additional confirmation is needed for branches that pass every check below.

1. Enumerate only task-owned disposable ticket, review-fix and skill-fix branches/worktrees recorded in `execution.json`. Inspect each current branch tip, `git worktree list --porcelain`, tracked/staged/untracked status and ignored task evidence. Do not infer ownership from a name prefix or delete the delivery branch.
2. A branch is eligible only when its work is verified and integrated and its worktree has no unsaved tracked, staged or untracked content. Prove integration either by finding its inspected tip in the PR HEAD's ancestry or, after a coordinator rebase, by mapping every task-owned commit from the recorded old delivery range to a reachable commit in the PR range with `git range-diff`. For automatic cleanup after a rebase, accept only exact `=` patch matches; a `!` similarity match is insufficient. Verify that the inspected branch tip is the recorded old tip, identify each exact matched new commit, and save the range-diff evidence. Retain branches with changed or unmatched commits, new commits, active workers, uncertain ownership, missing records or unsaved work.
3. If required ignored evidence has a durable summary outside an eligible worktree, try plain `git worktree remove`. If evidence must remain in place or plain removal refuses despite clean tracked/untracked status, detach the worktree at its inspected tip and retain it. Re-read branch tip and occupancy. For an ancestor tip, delete the unchanged unoccupied branch with `git branch -d`. For a proven rebase mapping, atomically move only the unchanged unoccupied branch ref from its inspected old tip to its equivalent commit reachable from PR HEAD, then delete it with `git branch -d`; record both SHAs. If `branch -d` refuses solely because its configured upstream is not merged, reconfirm that the unchanged tip is reachable from PR HEAD, unset that branch's local upstream, and retry `branch -d`. If any check, ref update or safe branch deletion fails, retain the resource and record the reason. Never use forced deletion.
4. Persist each removed worktree, deleted local branch and retained candidate with its checked tip and reason in `execution.json`. Verify remaining refs and worktrees, then report the PR result and any cleanup remainder. A successful PR with partial cleanup remains a successful PR with an explicit cleanup recovery point.

This step deletes local task-owned draft branches only. Remote refs and the delivery branch have their own lifecycle after the human merges the PR.
